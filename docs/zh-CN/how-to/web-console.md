# Web 控制台

[English](../../en/how-to/web-console.md) | [简体中文](web-console.md)

## 登录

访问控制器的 HTTPS 地址，GUI 与 API 使用同一监听器。先由 OP 签发[个人证书和令牌](certificates.md)，将 PKCS#12 包导入运行浏览器的电脑，并核对 CA 信任。Windows 使用 certmgr.msc 的当前用户“个人”证书库。

浏览器选择个人客户端证书后，填写控制面名称和配套个人令牌。令牌保存在当前标签页的会话存储中，刷新保留当前页面和登录，先向服务器核验身份再加载业务数据；到期、撤销或退出后清除，不写入长期本地存储。关闭标签页会结束会话；浏览器恢复已关闭标签页时可能同时恢复会话。引导 admin 凭据不能作为 GUI 日常身份；OP 应先用 CLI 创建具名管理员。登录后显示姓名、角色和凭据到期时间。右上角可切换简体中文和英文，并记住语言偏好。

证书包导出密码用于导入，个人令牌用于 API 登录，二者不同。ERR_BAD_SSL_CLIENT_AUTH_CERT 检查证书私钥、签发者、有效期和浏览器选择；Unauthorized 检查控制面名称、证书和令牌是否配对，以及身份是否停用。

如果页面加载前出现 ERR_SSL_DECRYPT_ERROR_ALERT，环境重建后仍使用旧客户端证书可能触发此错误。核对当前登录清单，导入该环境的新 P12 并信任其 CA；关闭全部浏览器进程后重新选择当前证书。Windows 可在 certmgr.msc 中移除对应环境的旧个人证书，并通过“Internet 选项 → 内容 → 清除 SSL 状态”清除缓存选择。页面打开后，再使用同一身份的当前令牌。

OP 可直接使用 `init.sh browser --file <收件人配置> --output <新目录>` 生成这套登录材料，或使用 `auth gui-login --with-credentials`。先准备私有输出父目录，交互输入 P12 密码；非交互使用 0600 密码文件。动作、输入与恢复规则见[初始化脚本](../reference/init-script.md)，完整交付步骤见[快速流程](../tutorials/quickstart.md)。

## 执行已有流程

1. 在“流程”选择已登记且启用的流程。
2. 选择预设目标，只能使用流程提供的选项。
3. 在“本次配置”的 K/V 表单修改变量、恢复默认值或新增本次变量；不可变变量只读。已有文件配置按允许修改的字段展示输入框。固定配置和来源只读。
4. 预览实际计划，核对目标、变量和工作项，并查看包含每个节点最终变量的脚本执行视图。
5. 执行后进入原 Run 详情，查看实际操作者、步骤、回执和日志。

无需人工审批。预览是配置一致性检查，流程或目标变化后需要重新预览。修改参数会使旧预览失效。本次覆盖不会保存为长期默认值。

## 页面与任务控制

| 页面 | 用途 |
| --- | --- |
| 流程 | 查看当前修订、来源、目标与参数并执行 |
| 任务 | 查看授权范围内任务、人员、实际配置快照、工作项与回执 |
| 节点 | 查看 Agent 心跳、主机资产和资源 |
| 外部目标 | 查看已登记的 Kubernetes API 等外部系统身份，不是流程的目标预设 |
| 审计 | 按实际登录身份追溯命令和结果 |
| 控制面 | 管理员查看成员配置与复制进度，不能据此认定单个成员健康 |

执行者只能暂停、恢复、取消自己的任务；管理员可控制全部。未知结果由管理员核验原证据后处置。取消不会回滚已经完成的修改。持续核对流程的暂停或取消也停止该代次继续产生修复任务。

流程、任务、节点、外部目标和审计列表统一支持每页 10/20/50/100 条，显示页号及本页记录范围，提供首页、上一页、下一页；长列表顶部和底部都有控件。读取中暂停翻页，失败时可返回已有页面。进入详情再返回、切换列表及 F5 后保留当前人员在该控制面中的翻页位置和每页条数。

任务列表提供“执行日期”和“结束日期”，按执行提交时间从新到旧分页排列。结束日期仅在任务进入成功、失败或已取消状态时记录；尚未结束或旧任务未留存该时间时显示“—”，不以归档时间代替。

后台读取失败时显示失败原因、上次成功时间和下次检查时间，过期数据不能用于提交。切换页面取消旧读取，不将迟到结果填到另一个资源。列表提供分页，日志支持原始保留内容下载和实时流。配置、审计与回执通过带标签的字段展示，不再直接输出 JSON；标识符、用户配置值和原始日志保留原文。

流程、脚本和连接秘密继续通过文件及 CLI 管理，人员与组授权可使用 GUI；详情见[资源模型](../reference/resources.md)和[CLI](../reference/cli.md)。

节点列表展示心跳、地址、CPU、内存、GPU 和系统。点击节点或直接访问 `#/nodes/NODE`，可查看分组资产、序列号、设备清单、采集错误及新鲜度；切换节点会取消旧读取，并隔离迟到响应。Run 工作项按计划顺序展示步骤、节点、阶段、操作、状态、退出码及原因，并可复制完整 Work ID。日志从确认的字节位置自动续读，避免重复显示，明确区分实时片段、回执尾部、过期、上传缺失和截断。完整下载核对返回的 SHA256，不会静默替换成回执尾部。

任务列表和详情显示从提交至结束的总用时，包含排队及暂停时间。进行中的任务每秒更新；历史任务缺少必要时间时显示“—”。点击步骤会高亮对应行，并定位到独立详情区。执行内容与原生回执的前后状态说明该步骤做了什么，技术字段与原始回执默认折叠。复制工作项编号后显示成功或失败反馈。脚本步骤可切换标准输出和标准错误、下载完整已保存日志，并区分等待输出、空输出、读取失败及仅有回执尾部等状态。

## 外部目标与流程预设

外部目标用于标识一个已有的平台，并引用它的连接配置。典型场景是向已有的 Kubernetes 集群发布应用：控制器通过插件调用该集群的 API，创建或更新 Deployment，再检查发布状态。

| 要做的事 | 选择的执行位置 | 执行方式 |
| --- | --- | --- |
| 在 VM 或物理机上写配置、管理服务、运行脚本 | 流程预设绑定的主机集群与节点 | 主机上的 Converyn Agent 执行 |
| 向已有 Kubernetes 集群发布应用 | 流程预设绑定的外部目标 | 控制器通过 Kubernetes API 执行 |

“目标预设”是流程提供的选项，例如“测试”或“生产”，决定本次操作的主机或平台。主机集群是供 Agent 执行的节点组；外部目标保存平台身份和连接配置的引用。一个混合流程的预设也可以同时绑定这两类位置，执行预览会列出各步骤的实际位置。

需要向 Kubernetes 发布应用时，由运维人员准备平台连接配置、登记外部目标及身份，再把流程的预设绑定到该目标。执行人员只需选择已有预设、预览并执行。示例关系：`生产预设 → 生产 Kubernetes 目标 → 该集群的 API`。目标登记和访问凭据由运维人员维护，详见[插件与连接](plugins.md)。

当前三套测试环境的 `demo` 流程使用 `ha`、`single`、`aio` 预设选择各自的 `hosts` 主机集群，由 Agent 执行文件和脚本操作。因此，外部目标列表为空时，这些主机流程仍可执行。页面会解释两种场景；流程详情会显示当前预设的绑定。

## 由 CLI 生成用户登录说明

使用目标用户的客户端配置执行 `converyn auth gui-login --output-dir ./gui-login`，可生成与实际环境、人员及证书匹配的中文说明和公开 CA。`--language en` 生成英文说明；`--with-credentials` 才会额外打包此人的 P12 和令牌，密码另行交付。默认说明不携带登录秘密，完整凭据包只能交付给对应人员本人。也可用 `converyn export credentials --ca --output ./ca.crt` 单独导出 CA。详见[个人证书与令牌](certificates.md)。

流程变量及节点默认值由 `values`、`node_values`、`immutable` 声明。未编辑的字段保留节点默认值；显式输入同名变量覆盖节点值。恢复默认值会撤销本次变量覆盖。日志记录本次有效变量，Secret 值脱敏。详见[流程变量](../../../example/workflow/README.zh-CN.md)。

参数区仅在有变量时显示列表；新增区支持类型选择和回车添加，错误会定位到对应输入框。“恢复默认值”统一撤销本次变量、步骤参数和文件内容的修改。手机上输入区按单列排列。

## 管理与授权

导航按实际能力展示。访问管理支持人员启停、用户组和角色授权；节点组管理支持成员维护和节点退役；外部目标支持使用现有控制器连接登记 Kubernetes 身份。流程维护者可启停流程。流程和脚本仍通过文件／Git 编写、CLI 登记；个人凭据通过 CLI 签发。见[人员与流程授权](access.md)。流程及任务过滤由服务端执行，过滤条件可通过页面地址分享。任务详情优先定位失败或需关注的工作项，支持步骤深链接。

宿主机存储挂载点保留常见本地持久化文件系统和主机 NFS/CIFS 共享；过滤 tmpfs、容器 overlay、Pod 卷及运行时内部挂载。同一块设备的重复绑定只展示一份，独立分区、Btrfs 子卷、ZFS 数据集和不同共享源保留。资产与资源使用同一规则，采集前筛选和去重，不执行挂载或磁盘修改。

状态用“几秒前更新／几分钟前检查”表示时效；超限省略按字段说明，例如“存储挂载点列表不完整”，并与采集失败分开。详情只展示已上报内容，不将被省略的列表误报为没有设备。资源及资产上限和周期保持不变。
